# Type Finnish and Special Characters using a US Keyboard
```{figure} https://raw.githubusercontent.com/HuangJiaLian/DataBase0/master/uploads/screenshot_260506_082724.png
:name: eukey 

The European Keyboard Layout {cite}`eukeyboard`. To type `ä`, you use `altgr + a`; to type `Ä`, you use `altgr + shift + a`.
```

Before buying a Finnish keyboard, I asked AI whether there was an alternative
that could save me the cost of buying a new keyboard. That is how I learned about
[EurKey](https://eurkey.steffen.bruentjen.eu/layout.html), which lets me type
Finnish characters very easily.

In Linux Mint, enable it by:
```bash
setxkbmap eu
```

You can type the Finnish characters `äåö` with `AltGr` + `a`, `w`, and `o`, and
use `AltGr` + `Shift` + `a`, `w`, and `o` to get the capital letters `ÄÅÖ`.
